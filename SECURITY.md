# Security policy

Sphinx parses untrusted files, so crashes, hangs and excessive memory use on crafted input are security bugs, as are leaks it claims to remove but does not (`sphinx seal` leaving data behind).

Report them privately through [GitHub security advisories](https://github.com/xCeg/Sphinx/security/advisories/new). Please include a minimal file that triggers the problem, made with invented content. You should get a first answer within a week.

Supported versions: the latest release.
