Questions people ask the Sphinx

Is my file sent anywhere?

No. The page loads a copy of Sphinx compiled to WebAssembly and runs it in your browser. There is no server behind this page, no analytics and no cookies, and the Content Security Policy stops the page from contacting any other site. Once loaded, it works with your network switched off.

How can it get back pixels I cropped?

Some editors saved a cropped picture by writing it over the original file without making the file shorter. The end of the original stays behind, compressed. Sphinx finds where a compressed block starts inside that leftover data, decodes it without the part that was overwritten, works out the original width from the patterns of the compression, and rebuilds the rows as an image. Colours drift where data is missing, but text usually stays readable.

If Sphinx finds nothing, is my file safe?

It means none of the questions found an answer. A file can still reveal something in a way Sphinx does not check, starting with what is plainly visible in it. Read what you send.

What does "clean" change?

For images it keeps the pixels, colour profile and orientation and drops everything else. For PDFs it writes the final version alone, without earlier revisions or document properties. For Office files and SVGs it removes properties, paths, editor data and the metadata of pictures inside; for zip archives, system files. It never removes tracked changes, comments, hidden layers or text under boxes: what a document says is your decision, so those stay in the report.

Someone sent me a file. Can I check it before giving it to an AI assistant?

Yes. "Hidden text addressed to AI tools" looks for instructions in text people cannot see, the way prompts are hidden in papers and CVs. A file that triggers it should not be handed to an assistant as it is.

Can I use it on many files or in CI?

Yes: the command-line tool reads folders, writes text, JSON, SARIF or Markdown, and can fail a build when a document about to be published leaks. See below.

For many files, use the command line

The same engine ships as a single binary with no dependencies. It reads folders, writes text, JSON, SARIF or Markdown, and fails a CI job when a document about to be published leaks.

$ go install github.com/xceg/sphinx/cmd/sphinx@latest
$ sphinx ~/Desktop/to-send/
$ sphinx reveal screenshot.png      # extract what it hides
$ sphinx seal holiday.jpg           # write holiday.sealed.jpg

Prebuilt binaries for Linux, macOS and Windows are on the releases page. The README covers CI, pre-commit and the Go library.
